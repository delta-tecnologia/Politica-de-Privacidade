Política de Privacidade

Desenvolvedor: Delta Tecnologia
Última atualização: 16 de novembro de 2026

1. Quem somos e a quais aplicativos esta política se aplica

Esta Política de Privacidade descreve como a Delta Tecnologia (“nós”), desenvolvedora responsável pelos aplicativos da linha Educar publicados no Google Play, coleta, usa, armazena e compartilha dados dos usuários. Ela se aplica aos seguintes aplicativos:

Aplicativo Identificador (pacote)
Educar Escola - PICOS com.deltatecnologia.educar_escola.picos
Educar Escola - ALTOLONGA com.deltatecnologia.educar_escola.altolonga
Educar Professor - PICOS com.deltatec.educar_professor.picos
Educar Professor - ALTOLONGÁ com.deltatec.educar_professor.altolonga
Educar Professor - TIMON com.deltatec.educar_professor.timon
Educar Responsável - PICOS com.deltatecnologia.educar_responsavel.picos
Educar Responsável - ALTOLONGÁ com.deltatecnologia.educar_responsavel.altolonga
Educar Responsável - TIMON com.deltatecnologia.educar_responsavel.timon
eDucar Avl - Picos com.deltatecnologia.educar_avaliacao.picos
eDucar Avl - Alto Longá com.deltatecnologia.educar_avaliacao.altolonga

Os aplicativos são fornecidos às redes municipais de ensino e se conectam ao sistema de gestão escolar Educar, também mantido pela Delta Tecnologia, por meio de uma API própria.

2. Dados coletados e finalidade

2.1 Educar Escola (PICOS e ALTOLONGA)

Aplicativo de uso exclusivo de servidores das escolas (gestores, secretários e professores) autorizados pela rede de ensino. Ele trata:

  • Dados de login: CPF e senha do servidor, usados apenas para autenticação no sistema Educar. O CPF do usuário conectado fica salvo no dispositivo para manter a sessão.
  • Fotos de servidores: capturadas pela câmera para cadastro e para registro de presença do servidor.
  • Imagens de gabaritos: fotos/leitura das folhas de resposta das avaliações dos alunos, usadas para corrigir e registrar os resultados.
  • Dados escolares: turmas, alunos, frequência (presença) e resultados de avaliações, sincronizados com o sistema Educar.
  • Códigos de barras/QR codes: lidos pela câmera para identificar documentos e alunos.

2.2 Educar Professor e eDucar Avl

Aplicativos de uso exclusivo de professores e servidores, que tratam dados de login e dados escolares (turmas, alunos, frequência, notas e avaliações) para registro das atividades pedagógicas.

2.3 Educar Responsável

Aplicativo para pais e responsáveis acompanharem notas e faltas dos alunos. Trata dados de login do responsável e exibe dados acadêmicos do aluno fornecidos pela API, sem armazená-los permanentemente no dispositivo.

2.4 Dados técnicos (todos os aplicativos que usam monitoramento)

Para identificar falhas e melhorar a estabilidade, os aplicativos podem enviar relatórios de erro e de desempenho, contendo modelo do dispositivo, versão do sistema operacional, versão do app, registros técnicos do erro e endereço IP.

3. Permissões do dispositivo

  • Internet: comunicação com a API do sistema Educar.
  • Câmera: captura de fotos de servidores, leitura de gabaritos e de códigos de barras/QR codes. A câmera só é usada quando o usuário abre essas funções.
  • Galeria/arquivos: seleção de imagens pelo usuário, quando aplicável.

4. Armazenamento no dispositivo

Para funcionar com conexão instável, alguns aplicativos (como o Educar Escola) mantêm uma cópia local temporária de dados escolares e de registros ainda não sincronizados. Esses dados ficam no armazenamento interno do app e são apagados ao sair da conta, limpar os dados do app ou desinstalá-lo.

5. Compartilhamento de dados

Não vendemos nem usamos os dados para publicidade. Os dados são compartilhados somente com:

  • A secretaria/rede municipal de ensino contratante, que é a responsável pelos dados escolares;
  • Sentry (Functional Software, Inc.), provedor de monitoramento de erros e desempenho, que recebe apenas os dados técnicos descritos no item 2.4 (política de privacidade do Sentry);
  • autoridades, quando exigido por lei.

6. Segurança

  • Comunicação com a API por conexão criptografada (HTTPS);
  • Acesso restrito a usuários autenticados e autorizados pela rede de ensino;
  • Boas práticas de desenvolvimento seguro para prevenir vulnerabilidades.

7. Retenção e exclusão de dados

Os dados escolares são mantidos no sistema Educar enquanto forem necessários para as finalidades educacionais e legais da rede de ensino. Relatórios técnicos de erro são retidos pelo período padrão do provedor de monitoramento. O usuário pode solicitar acesso, correção ou exclusão dos seus dados pessoais pelo e-mail de contato abaixo, nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

8. Crianças e adolescentes

Os aplicativos não são destinados ao uso por crianças. Dados de alunos são tratados somente por servidores autorizados e pelos responsáveis legais, no interesse do aluno e para fins educacionais.

9. Alterações nesta política

Podemos atualizar esta política periodicamente. A versão mais recente estará sempre disponível neste endereço, com a data de atualização indicada no topo.
